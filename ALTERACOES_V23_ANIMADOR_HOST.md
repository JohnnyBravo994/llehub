# v23 — Animador(a) e Host separados

- `Animador(a)` e `Host` passam a ser skills canónicas diferentes.
- Variantes `Animador`, `Animadora` e `Animador/a` normalizam para `Animador(a)`.
- `Host` mantém-se como skill própria.
- Registos antigos `Animador / Host` são migrados sem perda: a skill antiga é expandida para `Animador(a)` + `Host`, copiando os valores/classificação existentes para ambos, para depois poder ser afinado manualmente por colaborador.
- Registos antigos `Ator/Host` são expandidos para `Ator(a)` + `Host`.
- Agenda, Leads, autocomplete e mapeamento de serviços foram alinhados com esta separação.
